# Гиря каждый день

PWA для ежедневной гиревой практики: план на сегодня, таймер, дневник и автоматическая прогрессия нагрузки.
Работает офлайн, ставится на телефон как приложение, ничего никуда не отправляет — все данные лежат в браузере.

## Что умеет

- **План на сегодня.** Приложение само знает, какой сегодня день цикла, какая неделя блока
  и сколько подходов тебе давать. Ничего выбирать не нужно.
- **Три вопроса перед стартом** (сон, мышцы, силы) — и объём подстраивается под состояние.
- **Логирование.** Отметил подход — он записан. Можно поправить повторы и вес.
- **Таймер.** Отдых включается сам после подхода. Есть интервалы «каждую минуту» и секундомер.
  Звук, вибрация, экран не гаснет.
- **Прогрессия.** Две удачные тренировки подряд — приложение добавляет объём, потом убирает отдых,
  и только когда лестница пройдена, переводит на следующую гирю.
- **Мониторинг нагрузки.** Считает нагрузку по методу Фостера (RPE × минуты) и показывает,
  насколько резко ты прибавил. Это не предсказание травм — почему, написано в методике.
- **Тест кондиций.** Четыре коротких теста за одну сессию определяют рабочие веса и стартовые
  ступени, чтобы не начинать с нуля то, что уже умеешь.
- **Бюджет времени.** Говоришь, сколько есть минут — приложение упаковывает тренировку
  в них: сначала ставит движения в пары, потом сокращает отдых, и только в крайнем случае
  режет объём. Что именно оно сделало, пишет в плане дня.
- **Трекер добавок.** Только то, что имеет доказательную базу: пять добавок из консенсуса
  МОК, витамин D и омега-3 по показаниям. С отметками приёма, регулярностью и ссылками
  на источники. Отдельно перечислено популярное, на что не стоит тратить деньги.
- **Что дальше.** Когда лестницы почти пройдены, приложение говорит об этом и предлагает
  два хода: добрать недостающий паттерн или углубить текущий. Заодно заранее предупреждает,
  когда прогрессия упрётся в отсутствующую гирю или пару.
- **Шестнадцать программ:** ежедневный минимум, Simple & Sinister, «Путь бойца»,
  комплекс ABC, Quick and the Dead, The Giant, Iron Cardio, Easy Strength, A+A (план 025),
  Viking Warrior Conditioning, Soju and Tuba, гуманное бёрпи, 10 000 махов,
  гиревой спорт, «15 минут A/B», поддержка БЖЖ. У каждой указано происхождение, чем версия отличается
  от оригинала, что она даёт, чего не даёт и с чем не сочетается.

Методика подробно расписана в [docs/methodology.md](docs/methodology.md).

## Как запустить локально

```bash
python3 -m http.server 4178
```

Дальше открыть `http://localhost:4178`. Сборка не нужна — это чистый HTML/CSS/JS без зависимостей.

## Где живёт

Репозиторий: <https://github.com/smirsadykov/KB-daily>
Приложение: <https://smirsadykov.github.io/KB-daily/>

Публикация включается один раз: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
Дальше каждый `git push` в `main` обновляет сайт сам.

Все пути в проекте относительные, поэтому подпапка репозитория работает без правок.

## Как поставить на телефон

- **Android:** открыть ссылку в Chrome → меню → «Установить приложение».
- **iPhone:** открыть в Safari → «Поделиться» → «На экран "Домой"».

После установки работает офлайн.


## Обновление после правок кода

```bash
node tools/bump-version.mjs
```

Одна команда проставляет новую версию во всё сразу: `index.html`, `sw.js`,
все импорты модулей и список кэша. Дальше `git push` — и приложение обновится
у пользователя само при следующем запуске.

**Почему это важно делать одной командой.** Версия должна стоять на всех модулях,
а не только на `app.js`. Иначе при обновлении новый `app.js` может получить
из кэша старый модуль, не найти в нём нужный экспорт и упасть в пустой экран.

Если телефон всё-таки показывает старое: открыть адрес с любым хвостом,
например `https://smirsadykov.github.io/KB-daily/?x=1`.

## Данные

Всё хранится в localStorage браузера. В разделе «Ещё» есть выгрузка и загрузка JSON —
пользуйся перед сменой телефона или чисткой браузера.

## Проверка

```bash
node tools/audit.mjs
```

Гоняет 10400 проверок по всем программам, бюджетам времени и ступеням прогрессии:
баланс сторон, целостность парных блоков, соблюдение бюджета, полы отдыха,
логику прогрессии и совпадение подписей с фактическими подходами.

```bash
node tools/check-time.mjs
```

Сверяет расчёт времени с эталонными сессиями.

```bash
node tools/review.mjs
```

Аудит: целостность данных (битые ссылки, мёртвые упражнения, пробелы
в документации) и пригодность каждой программы — длительность от старта
до финала лестниц, сколько недель до конца прогрессии по каждому движению,
и влезает ли в бюджет времени. Здесь ловятся вещи, которые тесты не видят:
например, движение раз в неделю с лестницей в 14 ступеней формально работает,
но не закончится никогда.

## Насколько всему этому верить

В [методике](docs/methodology.md) у каждого утверждения стоит пометка: 🔬 — есть исследования
со ссылками, 🏋️ — тренерская традиция без экспериментального подтверждения,
⚙️ — выбор автора приложения, который мог быть другим. Ни один числовой параметр
здесь не выведен из исследования напрямую.

## Оговорка

Приложение не заменяет врача и не лечит боль. Острая боль — повод остановиться и разобраться,
а не «поработать полегче».
