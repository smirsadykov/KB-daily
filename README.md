# Гиря каждый день

PWA для ежедневной гиревой практики: план на сегодня, таймер, дневник и автоматическая прогрессия нагрузки.
Работает офлайн, ставится на телефон как приложение, ничего никуда не отправляет — все данные лежат в браузере.

## Что умеет

- **План на сегодня.** Приложение само знает, какой сегодня день цикла, какая неделя блока
  и сколько подходов тебе давать. Ничего выбирать не нужно.
- **Три вопроса перед стартом** (сон, мышцы, силы) — и объём подстраивается под состояние.
- **Логирование.** Отметил подход — он записан. Можно поправить повторы и вес.
- **Таймер.** Отдых включается сам после подхода. Есть интервалы «каждую минуту» и секундомер.
  Звук, вибрация, экран не гаснет.
- **Прогрессия.** Две удачные тренировки подряд — приложение добавляет объём, потом убирает отдых,
  и только когда лестница пройдена, переводит на следующую гирю.
- **Контроль перегруза.** Считает отношение свежей нагрузки к привычной и предупреждает о скачках.
- **Пять программ:** ежедневный минимум, Simple & Sinister, жимовые лестницы, комплекс ABC, поддержка БЖЖ.

Методика подробно расписана в [docs/methodology.md](docs/methodology.md).

## Как запустить локально

```bash
python3 -m http.server 4178
```

Дальше открыть `http://localhost:4178`. Сборка не нужна — это чистый HTML/CSS/JS без зависимостей.

## Как выложить на GitHub Pages

```bash
git init && git add -A && git commit -m "Гиря каждый день: первая версия"
git branch -M main
git remote add origin https://github.com/USERNAME/kettlebell-daily.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
Через минуту приложение будет по адресу `https://USERNAME.github.io/kettlebell-daily/`.

Все пути в проекте относительные, поэтому подпапка репозитория работает без правок.

## Как поставить на телефон

- **Android:** открыть ссылку в Chrome → меню → «Установить приложение».
- **iPhone:** открыть в Safari → «Поделиться» → «На экран "Домой"».

После установки работает офлайн.

## Структура

```

docs/methodology.md     методика: почему всё устроено именно так
```

## Обновление после правок кода

Service worker отдаёт файлы из кэша, но параллельно скачивает свежие, поэтому обновление
приезжает к следующему запуску приложения — вручную ничего делать не нужно.
Если понадобилось сбросить кэш целиком (например, файл переименовали),
подними версию в `sw.js`: `const VERSION = 'kbd-v2'`.

## Данные

Всё хранится в localStorage браузера. В разделе «Ещё» есть выгрузка и загрузка JSON —
пользуйся перед сменой телефона или чисткой браузера.

## Оговорка

Приложение не заменяет врача и не лечит боль. Острая боль — повод остановиться и разобраться,
а не «поработать полегче».
